Stats Analyzer

A statistical analysis tool with both a simple GUI and CLI for performing hypothesis testing, regression analysis, and statistical inference.

Python-based application for simplifying statistical analysis by providing:
  A GUI application for interactive analysis and visualization
  A CLI interface for quick statistical testing
  A modular backend implementing core statistical methods

One-sample tests:
  Z-test (known variance)
  T-test (unknown variance)
  Proportion test
  Variance test

Two-sample tests:
  Difference of means (Z & T)
  Paired T-test
  Difference of proportions

Variance & ANOVA
  F-test for comparing variances
  One-way ANOVA

Chi-Square Tests
  Goodness-of-fit test
  Test of independence

Regression Analysis
  Simple Linear Regression
  Multiple Linear Regression (via statsmodels)

Confidence Intervals
  Mean (Z and T intervals)
  Proportions
  Variance & Standard Deviation
  Sample size estimation

GUI Application
  Built using PyQt5
  Interactive forms for each statistical test
  Real-time results display
  Visualizations of distributions and rejection regions

CLI Support
  Run statistical tests directly in the terminal
  Guided prompts for input parameters
